# Product Landing Page mini-project

A responsive product landing page smartphone themed, built as part of web development minor project.

## built with

- HTML5
- Tailwind CSS
- CSS grid & Flexbox

## features

- responsive layout(mobile, tablet, desktop)
- sticky navigation bar
- A hero section
- feature cards made with CSS Grid
- Alternating benefits section built with flexbox/grid
- customer testimonial section
- pricing and final call to action section
- footer with contact info, socials and copyright
